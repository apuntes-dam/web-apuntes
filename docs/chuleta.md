# Chuleta

## HTML

| Quiero... | Etiqueta |
|---|---|
| Títulos | `<h1>`…`<h6>` |
| Párrafo · salto · línea | `<p>` · `<br>` · `<hr>` |
| Énfasis | `<strong>` · `<em>` |
| Enlace | `<a href="...">texto</a>` |
| Imagen | `<img src="..." alt="...">` |
| Listas | `<ul>`, `<ol>`, `<li>` · `<dl>`, `<dt>`, `<dd>` |
| Tabla | `<table>`, `<tr>`, `<th>`, `<td>` |
| Formulario | `<form>`, `<label>`, `<input>`, `<select>`, `<textarea>`, `<button>` |
| Estructura | `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>` |

## CSS

| Quiero... | Propiedad |
|---|---|
| Color de texto / fondo | `color` · `background-color` |
| Tipo y tamaño de letra | `font-family` · `font-size` |
| Espacios | `padding` (dentro) · `margin` (fuera) |
| Borde y esquinas | `border` · `border-radius` |
| Tamaño | `width` · `height` · `max-width` |
| Una fila flexible | `display: flex; justify-content; align-items; gap` |
| Una rejilla | `display: grid; grid-template-columns; gap` |
| Adaptar a móvil | `@media (max-width: 600px) { ... }` |

## JavaScript

| Quiero... | Código |
|---|---|
| Mostrar en consola | `console.log(x)` |
| Variable / constante | `let x` · `const x` |
| Seleccionar | `document.getElementById("id")` · `document.querySelector(".clase")` |
| Cambiar texto / estilo | `el.textContent = "..."` · `el.style.color = "red"` |
| Reaccionar a un evento | `el.addEventListener("click", () => {...})` |
| Crear y añadir | `document.createElement("p")` · `padre.appendChild(el)` |
| Leer un campo | `input.value` |
| Guardar en el navegador | `localStorage.setItem(k, v)` · `getItem(k)` |
| Pedir datos | `await fetch(url)` · `await respuesta.json()` |
