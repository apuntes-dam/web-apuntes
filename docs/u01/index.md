# U1 · HTML: la estructura de la web

**HTML** (*HyperText Markup Language*) es el lenguaje de marcado con el que se escribe el **contenido y la estructura** de una página web: títulos, párrafos, imágenes, enlaces, tablas y formularios. No es un lenguaje de programación: no tiene variables ni bucles, solo describe qué es cada cosa.

## Antes de empezar: qué debes dominar

* Qué es un navegador y cómo abrir un archivo `.html`.
* Crear y guardar archivos de texto con un editor (VS Code).
* Tener a mano la herramienta de desarrollo del navegador (tecla **F12**).
