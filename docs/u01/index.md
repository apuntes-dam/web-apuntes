# U1 · HTML: la estructura de la web

??? note "Leer el resumen"
    HTML es el lenguaje con el que se escribe la estructura de una página web. No es un lenguaje de programación: no tiene variables ni bucles, solo describe qué es cada cosa, un título, un párrafo, una imagen o un enlace.
    En esta unidad aprendes la estructura de una página, el texto y los enlaces, las imágenes y las listas, las tablas y los formularios.
    Y al final, la semántica y la accesibilidad: usar la etiqueta adecuada para cada cosa, para que la página la entiendan los buscadores y las personas que usan un lector de pantalla.


**HTML** (*HyperText Markup Language*) es el lenguaje de marcado con el que se escribe el **contenido y la estructura** de una página web: títulos, párrafos, imágenes, enlaces, tablas y formularios. No es un lenguaje de programación: no tiene variables ni bucles, solo describe qué es cada cosa.

* Qué es un navegador y cómo abrir un archivo `.html`.
* Crear y guardar archivos de texto con un editor (VS Code).
* Tener a mano la herramienta de desarrollo del navegador (tecla **F12**).
