# HTML, CSS y JavaScript

Apuntes y prácticas de **desarrollo web**: **HTML** para la estructura, **CSS** para el aspecto y **JavaScript** para el comportamiento. Casi todos los ejemplos tienen un **editor con vista previa**: puedes cambiar el código y ver el resultado al instante, sin instalar nada.

!!! info "Cómo está organizado"
    Cuatro unidades, de menos a más. Cada una tiene su teoría y, debajo, sus ejercicios, que se desbloquean al marcar la unidad como leída. Las soluciones modelo están bloqueadas (solo se ve el comienzo).

| Unidad | Contenido |
|---|---|
| [U1 · HTML](u01/index.md) | Estructura, texto, enlaces, imágenes, listas, tablas, formularios y semántica |
| [U2 · CSS](u02/index.md) | Selectores, color, modelo de caja, Flexbox, Grid y diseño adaptable |
| [U3 · JavaScript](u03/index.md) | Lenguaje, funciones, arrays, DOM, eventos, formularios, `localStorage` y `fetch` |
| [U4 · Proyectos](u04/index.md) | Pequeños proyectos que juntan HTML, CSS y JavaScript |
| [Chuleta](chuleta.md) | Etiquetas, propiedades y funciones más usadas |

!!! tip "Cómo trabajar"
    Crea siempre **tres archivos separados** (`index.html`, `estilos.css`, `script.js`), enlazados entre sí, y comprueba cada ejercicio en el navegador antes de pasar al siguiente. Con **F12** abres las herramientas de desarrollo: la consola te dice qué falla.

!!! note "¿Es HTML un lenguaje de programación?"
    No: HTML y CSS son lenguajes de **marcado** y de **estilos**. **JavaScript** sí es un lenguaje de programación, el único que ejecutan de forma nativa todos los navegadores. Si quieres comparar JavaScript con otros lenguajes, mira la [portada](https://apuntes-dam.github.io/apuntes-lenguajes/).
