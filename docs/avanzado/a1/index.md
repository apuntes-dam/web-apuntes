# WA1 · JavaScript moderno y asíncrono

El JavaScript que se escribe hoy no se parece al de hace diez años. Esta unidad enseña las herramientas que se usan **todos los días** en un proyecto real: sacar datos de objetos y listas con una línea, **módulos** para repartir el código en archivos, y sobre todo **lo asíncrono**: pedir datos, esperar y no bloquear la página.

## Teoría

1. [JavaScript moderno: datos, funciones y módulos](01-moderno.md)
2. [Asincronía: promesas, async/await y cancelación](02-asincrono.md)

## Antes de empezar: qué debes dominar

* La [unidad 3](../../u03/index.md): variables, funciones, arrays, objetos y `fetch` básico.
* Abrir la consola del navegador con **F12**. Para ejecutar los ejemplos fuera del navegador, [Node.js](https://nodejs.org/).
