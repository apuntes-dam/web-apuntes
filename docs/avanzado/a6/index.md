# WA6 · React

React es la librería de interfaces más usada hoy. No es un lenguaje nuevo: es JavaScript con una forma distinta de describir **qué se ve** a partir del estado, la misma idea que ya viste en la [WA2.2](../a2/02-apis.md#estado-vista-la-idea-detras-de-react-y-vue) con JavaScript puro. Aquí aprendes su sintaxis: componentes, JSX, props, estado y los *hooks* básicos.

## Teoría

1. [Componentes, JSX y props](01-componentes.md)
2. [Estado y eventos con hooks](02-estado-hooks.md)

## Antes de empezar: qué debes dominar

* La [WA2.2 Estado → vista](../a2/02-apis.md#estado-vista-la-idea-detras-de-react-y-vue): la idea que React pone en práctica.
* La [unidad 3.5 Eventos](../../u03/05-eventos.md): `onClick`/`onChange` en React son la misma idea con otro nombre.
