# WA4 · Movimiento, accesibilidad y rendimiento

Una página que se ve bien pero **no se puede usar con el teclado**, que **marea** con sus animaciones o que **tarda diez segundos en cargar** en un móvil con mala cobertura no está terminada. Esta unidad enseña a animar con criterio, a hacer la web **usable por todo el mundo** y a que **cargue rápido**.
