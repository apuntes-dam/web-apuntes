# WA3 · CSS moderno

El CSS de hoy resuelve con una línea cosas que antes pedían JavaScript o trucos: **temas** con una variable, **tipografías fluidas**, **estilos que dependen de si un elemento tiene un hijo concreto**, o componentes que se adaptan al **espacio que tienen** y no al tamaño de la pantalla. Esta unidad reúne lo que más cambia el día a día.

## Teoría

1. [Variables, funciones y selectores modernos](01-variables-selectores.md)
2. [Capas, adaptación por contenedor y layouts avanzados](02-capas-layout.md)

## Antes de empezar: qué debes dominar

* La [unidad 2](../../u02/index.md): selectores, modelo de caja, Flexbox, Grid y diseño adaptable.
* Abrir las herramientas del navegador (**F12**) y la pestaña *Elementos* para ver los estilos calculados.
