# WA5 · Herramientas, seguridad y despliegue

Un proyecto web real no es un `index.html` suelto: tiene **dependencias**, **pruebas automáticas**, un **formato de código** que comparte todo el equipo y una **forma de publicarse**. Y casi todos los fallos graves de una web son de **seguridad**. Esta unidad cierra el avanzado con las herramientas del oficio y con lo que hay que saber para no poner en riesgo a quien usa tu web.

## Antes de empezar: qué debes dominar

* La [WA1](../a1/index.md): módulos y `async/await`, y la [WA2](../a2/index.md): DOM y `fetch`.
* Tener instalado [Node.js](https://nodejs.org/) (trae `npm`) y saber usar una terminal. Si no, repasa la [web de Git](https://apuntes-dam.github.io/git-apuntes/).
