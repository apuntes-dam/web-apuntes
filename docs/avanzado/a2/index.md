# WA2 · DOM y eventos avanzados

En la [unidad 3](../../u03/index.md) aprendiste a seleccionar elementos y a reaccionar a un clic. Una página real tiene **cientos** de elementos que aparecen y desaparecen, datos que viajan por la URL, secciones que deben cargarse solo cuando se ven y formularios que se validan. Aquí aprendes las técnicas que mantienen todo eso **ordenado y rápido**.
